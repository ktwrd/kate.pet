Today 2 CVEs were dropped, both with a CVSS Score of 9.2. CVE-2026-109618, and CVE-2026-109619. If you want to wait for a patch, then you really should take anything publicly facing down and deploy the hotfix whenever the release is made, which should be at 2026-10-21 14:00 UTC.

If you want to mitigate now, and keep your stuff online, you'll have to disable session upload progress, which can break stuff. ([source](https://news.ycombinator.com/item?id=50175071))

To do this, append the following line to your php config (`/etc/php.ini`)
```
session.upload_progress.enabled = Off
```

And in your php-fpm pool configurations (`/etc/php-fpm.d/*.conf`), append the following line;
```
php_admin_flag[session.upload_progress.enabled] = off
```

Once you've done both of those things, restart the php-fpm service.
```bash
systemctl restart php-fpm
```


If you're on Windows, good luck? Or go find a different resource that gives you a more in-depth guide, but for the mitigation (at least right now) just append the same stuff to your config files.
