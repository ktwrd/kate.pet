## Mitigation

If you want to mitigate now, and keep your stuff online, you'll have to disable session upload progress, which can break stuff. ([source](https://news.ycombinator.com/item?id=50175071))

To do this, append the following line to your php config (`/etc/php.ini`)
```
session.upload_progress.enabled = Off
```

And in your php-fpm pool configurations (`/etc/php-fpm.d/*.conf`), append the following line;
```
php_admin_flag[session.upload_progress.enabled] = off
```

Once you've done both of those things, restart the php-fpm service.
```bash
systemctl restart php-fpm
```

### Validate

To then validate if the configuration value has been properly set, you can run the following command;
```bash
# for php
php -i | grep 'session.upload_progress.enabled'

# for php-fpm
php-fpm -i | grep 'session.upload_progress.enabled'
```

For both commands, it should output the following;
```bash
# php-fpm -i | grep 'session.upload_progress.enabled'
session.upload_progress.enabled => Off => Off
```

## Remarks;
- The security release that will be published later today, seems to only patch PHP 8. If you're running anything older, apply mitigations or shut down your servers and wait for an official mitigation from the PHP developers.
- If you cannot patch your servers, or you're not sure if this will fix it, then **shut down anything publicly facing.**
- If you're on Windows, look for those same config files, then restart whatever web server you're using.
